# arena · 裂谷竞技 · 素材清单

参考 Teeworlds 的俯视裂谷射击玩法（8 向移动、团队对抗、武器拾取）；只借鉴机制节奏与角色动画结构，角色、贴图、UI 主题全部自制，音乐另配。

**总量**：图片 182 张 / 音频 15 个
**P0 图片**：160 张（角色 136 + 武器 5 + 子弹 3 + 地形瓦片 16）
**参考源**：Teeworlds `datasrc/` 目录 —— CC-BY-SA 3.0（字体除外）；素材需 `scripts/build.py` 生成 `data/`。

## 三、规格要点（本项目特有）

- 角色是全项目最大的动画量：4 套 × 8 向 × 4 帧 + 射击 2 帧 = 136；实际出图按 **5 向 + 镜像**（左向水平翻转），排期仍按总账 136 的 8 向全量口径。
- 角色与武器同为 48×48，武器图只画**枪口挂点**，枪管朝向与右上光源一致，便于在角色手上对齐。
- 子弹 16×16 是全项目最小的战斗单位，只靠发光色与拖尾区分，不画纹理细节。
- 地形瓦片 16 张 = 地面6 / 墙4 / 装饰6；墙面高起=亮调、平地=中调、下陷=暗调，光源右上、阴影左下。
- 特效（枪口焰 / 命中 / 爆炸）走加色混合，源图不要自带描边，否则叠加后发灰。
- 音频格式统一 OGG Vorbis：SFX ≤1.5s 单声道、loop 2–4s 首尾波形对齐、BGM 60–120s 立体声（总账 §1.2）。
- **估算**：像素画 182 张 ≈ 91–182 + SFX 12 ≈ 3.6 + loop 2 ≈ 1 + BGM 1 ≈ 3 ≈ **98.6–189.6 人日**（口径：0.5–1 人日/张、0.3/SFX、0.5/loop、3/BGM）。

## 六、制作批次

- 批次 1（P0）：4 套角色 5 向帧 + 射击帧、5 件武器、3 种子弹、16 张地形瓦片。
- 批次 2（P1）：8 件掩体/道具、8 张特效、6 张 UI（准星 / 计分板 / 小地图优先）。
- 批次 3（音频）：12 个 SFX → 环境风 + 机器嗡鸣 2 个 loop → 1 首对战 BGM。
- 可复用：角色与地形色阶沿用总账统一基色阶；血条/队伍条底板可与 `cardarena` 的 UI 底板共用同一套灰阶。
